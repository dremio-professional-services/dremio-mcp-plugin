# Math and bitwise functions

Scope: Dremio Enterprise current [26.x]. Numeric coercion, precision, and invalid-domain behavior follow each linked page.

| Function | Documented syntax | Result | Constraint |
| --- | --- | --- | --- |
| [ABS](https://docs.dremio.com/current/reference/sql/sql-functions/functions/ABS/) | `ABS(numeric_expression numeric) → numeric` | Absolute value | Numeric input. |
| [CBRT](https://docs.dremio.com/current/reference/sql/sql-functions/functions/CBRT/) | `CBRT(numeric_expression numeric) → float` | Cube root | Numeric input. |
| [CEILING](https://docs.dremio.com/current/reference/sql/sql-functions/functions/CEILING/) | `CEILING(numeric_expression numeric) → integer` | Ceiling | Numeric input. |
| [FLOOR](https://docs.dremio.com/current/reference/sql/sql-functions/functions/FLOOR/) | `FLOOR(numeric_expression numeric) → integer` | Floor | Numeric input. |
| [SIGN](https://docs.dremio.com/current/reference/sql/sql-functions/functions/SIGN/) | `SIGN(numeric_expression numeric) → numeric` | Sign | Numeric input. |
| [SQRT](https://docs.dremio.com/current/reference/sql/sql-functions/functions/SQRT/) | `SQRT(double) → double`; `SQRT(int64) → int64`; `SQRT(int32) → int32`; `SQRT(float) → float` | Square root | Input must be in supported numeric domain. |
| [ACOS](https://docs.dremio.com/current/reference/sql/sql-functions/functions/ACOS/), [ASIN](https://docs.dremio.com/current/reference/sql/sql-functions/functions/ASIN/), [COS](https://docs.dremio.com/current/reference/sql/sql-functions/functions/COS/), [COSH](https://docs.dremio.com/current/reference/sql/sql-functions/functions/COSH/), [COT](https://docs.dremio.com/current/reference/sql/sql-functions/functions/COT/) | `ACOS\|ASIN\|COS\|COSH\|COT(numeric_expression numeric) → float` | Trigonometric result | Trigonometric input is radians. |
| [ATAN](https://docs.dremio.com/current/reference/sql/sql-functions/functions/ATAN/) | `ATAN(inputValue float) → float` | Arctangent | Float input. |
| [SIN](https://docs.dremio.com/current/reference/sql/sql-functions/functions/SIN/), [SINH](https://docs.dremio.com/current/reference/sql/sql-functions/functions/SINH/), [TAN](https://docs.dremio.com/current/reference/sql/sql-functions/functions/TAN/), [TANH](https://docs.dremio.com/current/reference/sql/sql-functions/functions/TANH/) | `SIN\|SINH\|TAN\|TANH(double\|int64\|int32\|float) → double` | Trigonometric result | Trigonometric input is radians. |
| [ATAN2](https://docs.dremio.com/current/reference/sql/sql-functions/functions/ATAN2/) | `ATAN2(y numeric, x numeric) → double` | Two-argument arctangent | Argument order matters. |
| [BROUND](https://docs.dremio.com/current/reference/sql/sql-functions/functions/BROUND/) | `BROUND(numeric_expression double) → float8` | Banker's rounded number | Current page has no scale overload. |
| [DEGREES](https://docs.dremio.com/current/reference/sql/sql-functions/functions/DEGREES/), [RADIANS](https://docs.dremio.com/current/reference/sql/sql-functions/functions/RADIANS/) | `DEGREES\|RADIANS(numeric_expression numeric) → float` | Converted angle | Inputs/returns use opposite angular units. |
| [E](https://docs.dremio.com/current/reference/sql/sql-functions/functions/E/), [PI](https://docs.dremio.com/current/reference/sql/sql-functions/functions/PI/) | `E()\|PI() → double` | Mathematical constant | Parentheses required. |
| [EXP](https://docs.dremio.com/current/reference/sql/sql-functions/functions/EXP/), [LN](https://docs.dremio.com/current/reference/sql/sql-functions/functions/LN/), [LOG10](https://docs.dremio.com/current/reference/sql/sql-functions/functions/LOG10/) | `EXP\|LN\|LOG10(numeric_expression numeric) → float` | Exponential/logarithm | Logarithm input must be positive. |
| [FACTORIAL](https://docs.dremio.com/current/reference/sql/sql-functions/functions/FACTORIAL/) | `FACTORIAL(integer) → bigint` | Integer factorial | Non-negative integer domain. |
| [LOG](https://docs.dremio.com/current/reference/sql/sql-functions/functions/LOG/) | `LOG(expression int32) → double`; `LOG(base_expression int32, expression int32) → double`; `LOG(expression int64) → double`; `LOG(base_expression int64, expression int64) → double`; `LOG(expression float) → double`; `LOG(base_expression float, expression float) → double`; `LOG(expression double) → double`; `LOG(base_expression double, expression double) → double` | Natural or base logarithm | Omitting `base_expression` calculates the natural logarithm. |
| [MOD](https://docs.dremio.com/current/reference/sql/sql-functions/functions/MOD/), [PMOD](https://docs.dremio.com/current/reference/sql/sql-functions/functions/PMOD/) | `MOD\|PMOD(dividend numeric, divisor numeric) → numeric` | Remainder | Divisor cannot be zero. |
| [POW, POWER](https://docs.dremio.com/current/reference/sql/sql-functions/functions/POW__POWER/) | `POW\|POWER(base numeric, exponent numeric) → double` | Raised power | Aliases share overload family. |
| [RANDOM](https://docs.dremio.com/current/reference/sql/sql-functions/functions/RANDOM/) | `RANDOM([seed int32]) → double` | Random number between 0 and 1 | `seed` is optional; a specified seed produces a repeatable sequence. |
| [ROUND](https://docs.dremio.com/current/reference/sql/sql-functions/functions/ROUND/) | `ROUND(decimal(0,0) [, scale int32]) → decimal(0,0)`; `ROUND(int32\|int64\|float\|double [, scale int32]) → int32\|int64\|float\|double` respectively | Rounded number | Scale overload uses `INT32`; return preserves each input type. |
| [TRUNCATE](https://docs.dremio.com/current/reference/sql/sql-functions/functions/TRUNCATE/) | `TRUNCATE(float) → int`; `TRUNCATE(double) → int`; `TRUNCATE(int32) → int32`; `TRUNCATE(int64) → int64`; `TRUNCATE(decimal(0,0)) → decimal(0,0)`; `TRUNCATE(float\|double\|int32\|int64\|decimal(0,0), scale int32) → float\|double\|int32\|int64\|decimal(0,0)` respectively | Truncated number | Unscaled `FLOAT`/`DOUBLE` return `INT`; scaled return preserves each input type. |
| [STDDEV](https://docs.dremio.com/current/reference/sql/sql-functions/functions/STDDEV/), [STDDEV_POP](https://docs.dremio.com/current/reference/sql/sql-functions/functions/STDDEV_POP/), [STDDEV_SAMP](https://docs.dremio.com/current/reference/sql/sql-functions/functions/STDDEV_SAMP/) | `STDDEV\|STDDEV_POP\|STDDEV_SAMP(numeric) → double` | Standard deviation | Aggregate/window context required. |
| [BITWISE_AND](https://docs.dremio.com/current/reference/sql/sql-functions/functions/BITWISE_AND/), [BITWISE_OR](https://docs.dremio.com/current/reference/sql/sql-functions/functions/BITWISE_OR/), [BITWISE_XOR](https://docs.dremio.com/current/reference/sql/sql-functions/functions/BITWISE_XOR/) | `BITWISE_AND\|BITWISE_OR\|BITWISE_XOR(op1 numeric, op2 numeric) → numeric` | Bitwise result | Numeric inputs. |
| [XOR](https://docs.dremio.com/current/reference/sql/sql-functions/functions/XOR/) | `XOR(expression1 int32, expression2 int32) → int32` | Bitwise XOR | `INT32` inputs. |
| [BITWISE_NOT](https://docs.dremio.com/current/reference/sql/sql-functions/functions/BITWISE_NOT/) | `BITWISE_NOT(op1 numeric) → numeric` | Bitwise complement | Numeric input. |
| [BIT_AND](https://docs.dremio.com/current/reference/sql/sql-functions/functions/BIT_AND/), [BIT_OR](https://docs.dremio.com/current/reference/sql/sql-functions/functions/BIT_OR/) | `BIT_AND\|BIT_OR(expression int) → int` | Aggregate bitwise result | Aggregate functions, unlike `BITWISE_*`. |
| [LSHIFT](https://docs.dremio.com/current/reference/sql/sql-functions/functions/LSHIFT/), [RSHIFT](https://docs.dremio.com/current/reference/sql/sql-functions/functions/RSHIFT/) | `LSHIFT\|RSHIFT(value int64, shift int32) → int64` | Shifted integer | Shift count is `INT32`. |
