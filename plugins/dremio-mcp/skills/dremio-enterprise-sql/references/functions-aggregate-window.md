# Aggregate, Window, and Percentile functions

Scope: Dremio Enterprise current [26.x]. Each entry links its current public reference; apply only the linked page's syntax and limits.

## Aggregate

| Function | Documented syntax | Result | Constraint |
| --- | --- | --- | --- |
| [APPROX_COUNT_DISTINCT](https://docs.dremio.com/current/reference/sql/sql-functions/functions/APPROX_COUNT_DISTINCT/) | `APPROX_COUNT_DISTINCT(column_name any primitive) → bigint` | Approximate non-null distinct count | Aggregate expression; approximation intentional. |
| [ARRAY_AGG](https://docs.dremio.com/current/reference/sql/sql-functions/functions/ARRAY_AGG/) | `ARRAY_AGG([DISTINCT] expression) → array` | Array of input values | Aggregate form. |
| [ARRAY_AVG](https://docs.dremio.com/current/reference/sql/sql-functions/functions/ARRAY_AVG/), [ARRAY_MAX](https://docs.dremio.com/current/reference/sql/sql-functions/functions/ARRAY_MAX/), [ARRAY_MIN](https://docs.dremio.com/current/reference/sql/sql-functions/functions/ARRAY_MIN/), [ARRAY_SUM](https://docs.dremio.com/current/reference/sql/sql-functions/functions/ARRAY_SUM/) | `ARRAY_AVG\|ARRAY_MAX\|ARRAY_MIN\|ARRAY_SUM(list_column list) → numeric` | List aggregate | Null elements follow individual page semantics. |
| [AVG](https://docs.dremio.com/current/reference/sql/sql-functions/functions/AVG/) | `AVG(numeric_expression numeric) → double` | Numeric average | Null input excluded. |
| [SUM](https://docs.dremio.com/current/reference/sql/sql-functions/functions/SUM/) | `SUM(numeric) → input type; int → bigint` | Numeric sum | Null input excluded. |
| [BIT_AND](https://docs.dremio.com/current/reference/sql/sql-functions/functions/BIT_AND/) | `BIT_AND(expression int) → int` | Aggregate bitwise AND | Integer input. |
| [BIT_OR](https://docs.dremio.com/current/reference/sql/sql-functions/functions/BIT_OR/) | `BIT_OR(expression int) → int` | Aggregate bitwise OR | Integer input. |
| [CORR](https://docs.dremio.com/current/reference/sql/sql-functions/functions/CORR/) | `CORR(expression1 numeric, expression2 numeric) → double` | Pearson correlation | Function name is quoted as documented. |
| [COVAR_POP](https://docs.dremio.com/current/reference/sql/sql-functions/functions/COVAR_POP/) | `COVAR_POP(expression1 numeric, expression2 numeric) → double` | Population covariance | Numeric pairs. |
| [COVAR_SAMP](https://docs.dremio.com/current/reference/sql/sql-functions/functions/COVAR_SAMP/) | `COVAR_SAMP(expression1 numeric, expression2 numeric) → double` | Sample covariance | Numeric pairs. |
| [COUNT](https://docs.dremio.com/current/reference/sql/sql-functions/functions/COUNT/) | `COUNT(*) → bigint`; `COUNT(expression any) → bigint` | Row or non-null expression count | `COUNT(expression)` excludes nulls. |
| [LISTAGG](https://docs.dremio.com/current/reference/sql/sql-functions/functions/LISTAGG/) | `LISTAGG(expression varchar [, delimiter varchar]) → varchar` | Concatenated string | Use documented ordering form when ordering matters. |
| [MAX](https://docs.dremio.com/current/reference/sql/sql-functions/functions/MAX/) | `MAX(expression any) → input type` | Maximum non-null value | Aggregate/window context as documented. |
| [MIN](https://docs.dremio.com/current/reference/sql/sql-functions/functions/MIN/) | `MIN(expression any) → input type` | Minimum non-null value | Aggregate/window context as documented. |
| [MEDIAN](https://docs.dremio.com/current/reference/sql/sql-functions/functions/MEDIAN/) | `MEDIAN(expression numeric) → double` | Continuous-distribution median | Numeric input. |
| [NDV](https://docs.dremio.com/current/reference/sql/sql-functions/functions/NDV/) | `NDV(expression numeric [, scale numeric]) → bigint` | Approximate distinct-value count | Scale range is `1`–`10`; the usage notes also permit `DISTINCT` or `ALL`. |
| [STDDEV](https://docs.dremio.com/current/reference/sql/sql-functions/functions/STDDEV/), [STDDEV_POP](https://docs.dremio.com/current/reference/sql/sql-functions/functions/STDDEV_POP/), [STDDEV_SAMP](https://docs.dremio.com/current/reference/sql/sql-functions/functions/STDDEV_SAMP/) | `STDDEV\|STDDEV_POP\|STDDEV_SAMP(numeric) → double` | Standard deviation | All-null group returns null. |
| [VAR_POP](https://docs.dremio.com/current/reference/sql/sql-functions/functions/VAR_POP/), [VAR_SAMP](https://docs.dremio.com/current/reference/sql/sql-functions/functions/VAR_SAMP/) | `VAR_POP\|VAR_SAMP(numeric) → numeric` | Population/sample variance | Numeric input. |

## Window and percentile

| Function | Documented syntax | Result | Constraint |
| --- | --- | --- | --- |
| [CUME_DIST](https://docs.dremio.com/current/reference/sql/sql-functions/functions/CUME_DIST/) | `CUME_DIST() OVER ([PARTITION BY partition_expression] [ORDER BY order_expression]) → double` | Cumulative distribution | Window frame clause is not supported. |
| [PERCENT_RANK](https://docs.dremio.com/current/reference/sql/sql-functions/functions/PERCENT_RANK/) | `PERCENT_RANK() OVER ([PARTITION BY partition_expression] ORDER BY order_expression) → double` | Relative rank | `ORDER BY` is required. |
| [DENSE_RANK](https://docs.dremio.com/current/reference/sql/sql-functions/functions/DENSE_RANK/), [RANK](https://docs.dremio.com/current/reference/sql/sql-functions/functions/RANK/), [ROW_NUMBER](https://docs.dremio.com/current/reference/sql/sql-functions/functions/ROW_NUMBER/) | `DENSE_RANK\|RANK\|ROW_NUMBER() OVER ([PARTITION BY partition_expression] [ORDER BY order_expression]) → bigint` | Dense rank, rank, or row number | Both clauses optional. |
| [FIRST_VALUE](https://docs.dremio.com/current/reference/sql/sql-functions/functions/FIRST_VALUE/) | `FIRST_VALUE(expression) OVER (PARTITION BY partition_expression ORDER BY order_expression)` | First value in the ordered window | The page heading shows `FIRST_VALUE(expression VARCHAR, order_subclause VARCHAR) → VARCHAR`, but its examples use this one-expression window form with `pop`; do not pass `order_subclause` as a second call argument or infer settled VARCHAR-only types. |
| [LAST_VALUE](https://docs.dremio.com/current/reference/sql/sql-functions/functions/LAST_VALUE/) | `LAST_VALUE(expression) OVER (PARTITION BY partition_expression ORDER BY order_expression)` | Last value in the ordered window | The page heading shows `LAST_VALUE(expression VARCHAR, order_subclause VARCHAR) → VARCHAR`, but its examples use this one-expression window form with `pop`; do not pass `order_subclause` as a second call argument or infer settled VARCHAR-only types. |
| [LAG](https://docs.dremio.com/current/reference/sql/sql-functions/functions/LAG/), [LEAD](https://docs.dremio.com/current/reference/sql/sql-functions/functions/LEAD/) | `LAG\|LEAD(expression [, offset]) OVER ([PARTITION BY partition_expression] [ORDER BY order_expression]) → same input type` | Prior or following value | Partition/order and offset optional; no default argument. |
| [NTILE](https://docs.dremio.com/current/reference/sql/sql-functions/functions/NTILE/) | `NTILE(buckets) OVER ([PARTITION BY partition_expression] ORDER BY order_expression) → int` | Bucket number | `buckets` is a positive integer literal; `ORDER BY` is required. |
| [APPROX_PERCENTILE](https://docs.dremio.com/current/reference/sql/sql-functions/functions/APPROX_PERCENTILE/) | `APPROX_PERCENTILE(column_name numeric, percentile double) → double` | Approximate percentile | Percentile in documented range. |
| [PERCENTILE_CONT](https://docs.dremio.com/current/reference/sql/sql-functions/functions/PERCENTILE_CONT/), [PERCENTILE_DISC](https://docs.dremio.com/current/reference/sql/sql-functions/functions/PERCENTILE_DISC/) | `PERCENTILE_CONT\|PERCENTILE_DISC(percentile double) WITHIN GROUP (ORDER BY numeric) → double` | Continuous/discrete percentile | `WITHIN GROUP` ordering required. |
| [AVG](https://docs.dremio.com/current/reference/sql/sql-functions/functions/AVG/) | `AVG(numeric_expression numeric) OVER ([PARTITION BY expression] [ORDER BY expression] [frame]) → double` | Window average | Window clauses/frame only as page supports. |
| [COUNT](https://docs.dremio.com/current/reference/sql/sql-functions/functions/COUNT/) | `COUNT(expression any) OVER ([PARTITION BY expression] [ORDER BY expression] [frame]) → bigint` | Window count | `COUNT(expression)` excludes nulls. |
| [COVAR_POP](https://docs.dremio.com/current/reference/sql/sql-functions/functions/COVAR_POP/), [COVAR_SAMP](https://docs.dremio.com/current/reference/sql/sql-functions/functions/COVAR_SAMP/) | `COVAR_POP\|COVAR_SAMP(expression1 numeric, expression2 numeric) OVER ([PARTITION BY expression] [ORDER BY expression] [frame]) → double` | Window covariance | Numeric pairs required. |
| [MAX](https://docs.dremio.com/current/reference/sql/sql-functions/functions/MAX/), [MIN](https://docs.dremio.com/current/reference/sql/sql-functions/functions/MIN/) | `MAX\|MIN(expression numeric) OVER ([PARTITION BY expression] [ORDER BY expression] [frame]) → numeric input type` | Window extrema | Numeric input. |
| [NDV](https://docs.dremio.com/current/reference/sql/sql-functions/functions/NDV/) | `NDV(expression numeric [, scale numeric]) → bigint` | Approximate distinct-value count | The current page cross-lists NDV under Window but documents no `OVER` syntax; do not infer one. |
| [STDDEV_POP](https://docs.dremio.com/current/reference/sql/sql-functions/functions/STDDEV_POP/), [STDDEV_SAMP](https://docs.dremio.com/current/reference/sql/sql-functions/functions/STDDEV_SAMP/) | `STDDEV_POP\|STDDEV_SAMP(col_name numeric) OVER ([PARTITION BY expression] [ORDER BY expression] [frame]) → double` | Window standard deviation | Numeric input. |
| [SUM](https://docs.dremio.com/current/reference/sql/sql-functions/functions/SUM/) | `SUM(col_name numeric) OVER ([PARTITION BY expression] [ORDER BY expression] [frame]) → input type; int → bigint` | Window sum | Numeric input. |
| [VAR_POP](https://docs.dremio.com/current/reference/sql/sql-functions/functions/VAR_POP/), [VAR_SAMP](https://docs.dremio.com/current/reference/sql/sql-functions/functions/VAR_SAMP/) | `VAR_POP\|VAR_SAMP(col_name numeric) OVER ([PARTITION BY expression] [ORDER BY expression] [frame]) → numeric` | Window variance | Numeric input. |
