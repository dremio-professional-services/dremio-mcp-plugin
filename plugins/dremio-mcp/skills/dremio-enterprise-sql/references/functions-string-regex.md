# String and regular-expression functions

Scope: Dremio Enterprise current [26.x]. String position, indexing, and regular-expression dialect details are defined by each linked page.

| Function | Documented syntax | Result | Constraint |
| --- | --- | --- | --- |
| [ASCII](https://docs.dremio.com/current/reference/sql/sql-functions/functions/ASCII/) | `ASCII(expression varchar) → int32` | ASCII code | Varchar input. |
| [CHR](https://docs.dremio.com/current/reference/sql/sql-functions/functions/CHR/) | `CHR(integer_expression int32) → varchar` | Character | `INT32` input. |
| [BASE64](https://docs.dremio.com/current/reference/sql/sql-functions/functions/BASE64/), [UNBASE64](https://docs.dremio.com/current/reference/sql/sql-functions/functions/UNBASE64/), [CRC32](https://docs.dremio.com/current/reference/sql/sql-functions/functions/CRC32/), [FROM_HEX](https://docs.dremio.com/current/reference/sql/sql-functions/functions/FROM_HEX/), [HEX](https://docs.dremio.com/current/reference/sql/sql-functions/functions/HEX/), [TO_HEX](https://docs.dremio.com/current/reference/sql/sql-functions/functions/TO_HEX/), [UNHEX](https://docs.dremio.com/current/reference/sql/sql-functions/functions/UNHEX/) | `BASE64(varbinary) → varchar`; `UNBASE64(varchar) → varbinary`; `CRC32(varbinary) → varchar`; hex conversion is `varchar ↔ varbinary` | Encoded/decoded/checksum value | Binary/varchar direction is fixed per named function. |
| [BTRIM](https://docs.dremio.com/current/reference/sql/sql-functions/functions/BTRIM/) | `BTRIM(expression string [, trim_text string]) → string` | Trimmed string | Trim text optional. |
| [LTRIM](https://docs.dremio.com/current/reference/sql/sql-functions/functions/LTRIM/) | `LTRIM(expression varchar) → varchar`; `LTRIM(expression varchar, trim_expression varchar) → varchar` | Left-trimmed string | `trim_expression` is optional; omitting it trims spaces. |
| [RTRIM](https://docs.dremio.com/current/reference/sql/sql-functions/functions/RTRIM/) | `RTRIM(expression varchar [, trim_expression varchar]) → varchar` | Right-trimmed string | Trim expression optional. |
| [TRIM](https://docs.dremio.com/current/reference/sql/sql-functions/functions/TRIM/) | `TRIM(expression varchar) → varchar`; `TRIM(trim_expression varchar FROM expression varchar) → varchar`; `TRIM(LEADING\|TRAILING\|BOTH [trim_expression varchar] FROM expression varchar) → varchar` | Trimmed string | Direction defaults to `BOTH`; `trim_expression` defaults to a space. |
| [CHARACTER_LENGTH](https://docs.dremio.com/current/reference/sql/sql-functions/functions/CHARACTER_LENGTH/) | `CHARACTER_LENGTH(expression varchar) → int32` | Character length | Varchar input. |
| [CHAR_LENGTH](https://docs.dremio.com/current/reference/sql/sql-functions/functions/CHAR_LENGTH/) | `CHAR_LENGTH(expression string) → integer` | Character length | String input. |
| [LENGTH](https://docs.dremio.com/current/reference/sql/sql-functions/functions/LENGTH/) | `LENGTH([expression varchar]) → int32` | String length | Argument is optional. |
| [OCTET_LENGTH](https://docs.dremio.com/current/reference/sql/sql-functions/functions/OCTET_LENGTH/) | `OCTET_LENGTH(input varchar) → int32` | Byte length | Varchar input. |
| [COL_LIKE](https://docs.dremio.com/current/reference/sql/sql-functions/functions/COL_LIKE/) | `COL_LIKE(expression_col varchar, pattern_col varchar) → boolean` | Column pattern predicate | Varchar inputs. |
| [CONTAINS](https://docs.dremio.com/current/reference/sql/sql-functions/functions/CONTAINS/) | `CONTAINS(luceneExpression varchar) → dataset` | Lucene search result | Context is search, not a scalar predicate. |
| [ENDS_WITH](https://docs.dremio.com/current/reference/sql/sql-functions/functions/ENDS_WITH/), [STARTS_WITH](https://docs.dremio.com/current/reference/sql/sql-functions/functions/STARTS_WITH/) | `ENDS_WITH\|STARTS_WITH(expression1 string, expression2 string) → bit` | Prefix/suffix predicate | String inputs. |
| [CONCAT](https://docs.dremio.com/current/reference/sql/sql-functions/functions/CONCAT/) | `CONCAT(expression1 string [, expression2 string] [, expressionN string]) → string` | Concatenated string | At least first expression is required. |
| [CONCAT_WS](https://docs.dremio.com/current/reference/sql/sql-functions/functions/CONCAT_WS/) | `CONCAT_WS(separator) → string`; `CONCAT_WS(separator, expression1, expression2 [, ... expressionN]) → string` | Separator-joined string | The separator-only form returns an empty string; with expressions, all arguments must have the same data type. |
| [ILIKE](https://docs.dremio.com/current/reference/sql/sql-functions/functions/ILIKE/), [LIKE](https://docs.dremio.com/current/reference/sql/sql-functions/functions/LIKE/), [SIMILAR_TO](https://docs.dremio.com/current/reference/sql/sql-functions/functions/SIMILAR_TO/) | `varchar ILIKE\|LIKE\|SIMILAR TO pattern varchar → boolean` | Pattern predicate | Operators have distinct pattern semantics. |
| [INITCAP](https://docs.dremio.com/current/reference/sql/sql-functions/functions/INITCAP/), [LCASE](https://docs.dremio.com/current/reference/sql/sql-functions/functions/LCASE/), [LOWER](https://docs.dremio.com/current/reference/sql/sql-functions/functions/LOWER/), [UCASE](https://docs.dremio.com/current/reference/sql/sql-functions/functions/UCASE/), [UPPER](https://docs.dremio.com/current/reference/sql/sql-functions/functions/UPPER/) | `INITCAP\|LCASE\|LOWER\|UCASE\|UPPER(expression varchar) → varchar` | Case-normalized string | Varchar input. |
| [INSTR](https://docs.dremio.com/current/reference/sql/sql-functions/functions/INSTR/) | `INSTR(expression1 string, expression2 string) → int` | Substring position | Argument order fixed. |
| [LOCATE](https://docs.dremio.com/current/reference/sql/sql-functions/functions/LOCATE/) | `LOCATE(substring varchar, expression varchar [, start int32]) → int32` | Substring position | Substring is first. |
| [POSITION](https://docs.dremio.com/current/reference/sql/sql-functions/functions/POSITION/) | `POSITION(substr string IN expression string) → integer` | Substring position | Uses `IN` grammar. |
| [STRPOS](https://docs.dremio.com/current/reference/sql/sql-functions/functions/STRPOS/) | `STRPOS(expression varchar, substring varchar) → int32` | Substring position | Expression is first. |
| [IS_UTF8](https://docs.dremio.com/current/reference/sql/sql-functions/functions/IS_UTF8/) | `IS_UTF8(binary) → boolean` | UTF-8 validity predicate | Binary input. |
| [LEFT](https://docs.dremio.com/current/reference/sql/sql-functions/functions/LEFT/) | `LEFT(expression varchar, length int64) → varchar` | Left portion | Length is `INT64`. |
| [RIGHT](https://docs.dremio.com/current/reference/sql/sql-functions/functions/RIGHT/) | `RIGHT(string varchar, length int64) → varchar` | Right portion | Length is `INT64`. |
| [LEVENSHTEIN](https://docs.dremio.com/current/reference/sql/sql-functions/functions/LEVENSHTEIN/) | `LEVENSHTEIN(string1 varchar, string2 varchar) → int32` | Edit distance | String inputs. |
| [LPAD](https://docs.dremio.com/current/reference/sql/sql-functions/functions/LPAD/) | `LPAD(varchar, length int64) → varchar`; `LPAD(varchar, length int64, pad varchar) → varchar` | Left-padded/truncated string | Two- and three-argument overloads distinct. |
| [MASK](https://docs.dremio.com/current/reference/sql/sql-functions/functions/MASK/) | `MASK(varchar [, uc_mask varchar] [, lc_mask varchar] [, num_mask varchar]) → varchar` | Masked string | Optional masks are ordered upper/lower/numeric. |
| [MASK_FIRST_N](https://docs.dremio.com/current/reference/sql/sql-functions/functions/MASK_FIRST_N/), [MASK_LAST_N](https://docs.dremio.com/current/reference/sql/sql-functions/functions/MASK_LAST_N/), [MASK_SHOW_FIRST_N](https://docs.dremio.com/current/reference/sql/sql-functions/functions/MASK_SHOW_FIRST_N/), [MASK_SHOW_LAST_N](https://docs.dremio.com/current/reference/sql/sql-functions/functions/MASK_SHOW_LAST_N/) | `MASK_FIRST_N\|MASK_LAST_N\|MASK_SHOW_FIRST_N\|MASK_SHOW_LAST_N(varchar [, num_chars int] [, uc_mask varchar] [, lc_mask varchar] [, num_mask varchar]) → varchar` | Positional masked string | Optional parameters are ordered and `num_chars` is `INT`. |
| [MASK_HASH](https://docs.dremio.com/current/reference/sql/sql-functions/functions/MASK_HASH/) | `MASK_HASH(expression varchar) → varchar` | Hash-masked string | Varchar input. |
| [NORMALIZE_STRING](https://docs.dremio.com/current/reference/sql/sql-functions/functions/NORMALIZE_STRING/) | `NORMALIZE_STRING(string varchar [, form varchar]) → varchar` | Unicode-normalized string | Normalization form documented. |
| [PARSE_URL](https://docs.dremio.com/current/reference/sql/sql-functions/functions/PARSE_URL/) | `PARSE_URL(url varchar, part varchar [, key varchar]) → varchar` | URL component | Part/key values documented. |
| [QUOTE](https://docs.dremio.com/current/reference/sql/sql-functions/functions/QUOTE/) | `QUOTE(string varchar) → varchar` | Quoted string | Escapes follow page semantics. |
| [REGEXP_COL_LIKE](https://docs.dremio.com/current/reference/sql/sql-functions/functions/REGEXP_COL_LIKE/) | `REGEXP_COL_LIKE(input string, regex string) → boolean` | Regex predicate | String input and regex. |
| [REGEXP_EXTRACT](https://docs.dremio.com/current/reference/sql/sql-functions/functions/REGEXP_EXTRACT/) | `REGEXP_EXTRACT(input string, regex string [, expr_group_index integer]) → string` | Extracted match | Group index optional. |
| [REGEXP_LIKE](https://docs.dremio.com/current/reference/sql/sql-functions/functions/REGEXP_LIKE/), [REGEXP_MATCHES](https://docs.dremio.com/current/reference/sql/sql-functions/functions/REGEXP_MATCHES/) | `REGEXP_LIKE\|REGEXP_MATCHES(input string, regex string) → boolean` | Regex predicate | String input and regex. |
| [REGEXP_REPLACE](https://docs.dremio.com/current/reference/sql/sql-functions/functions/REGEXP_REPLACE/) | `REGEXP_REPLACE(input string, regex string, replacement_string string) → string` | Replaced string | Replacement required. |
| [REGEXP_SPLIT](https://docs.dremio.com/current/reference/sql/sql-functions/functions/REGEXP_SPLIT/) | `REGEXP_SPLIT(input string, regex string, keyword string, integer integer) → array` | Split array | All four arguments required. |
| [REPEAT](https://docs.dremio.com/current/reference/sql/sql-functions/functions/REPEAT/), [REPEATSTR](https://docs.dremio.com/current/reference/sql/sql-functions/functions/REPEATSTR/) | `REPEAT\|REPEATSTR(expression varchar, nTimes int32) → varchar` | Repeated string | Count is `INT32`. |
| [REPLACE](https://docs.dremio.com/current/reference/sql/sql-functions/functions/REPLACE/) | `REPLACE(varchar, pattern varchar, replacement varchar) → varchar` | Replaced string | Pattern/replacement required. |
| [REVERSE](https://docs.dremio.com/current/reference/sql/sql-functions/functions/REVERSE/) | `REVERSE(expression varchar) → varchar` | Reversed string | Varchar input. |
| [RPAD](https://docs.dremio.com/current/reference/sql/sql-functions/functions/RPAD/) | `RPAD(base_expression varchar, length int64 [, pad_expression varchar]) → varchar` | Right-padded string | Pad expression optional. |
| [SOUNDEX](https://docs.dremio.com/current/reference/sql/sql-functions/functions/SOUNDEX/) | `SOUNDEX(expression varchar) → varchar` | Soundex code | Varchar input. |
| [SPLIT_PART](https://docs.dremio.com/current/reference/sql/sql-functions/functions/SPLIT_PART/) | `SPLIT_PART(varchar, delimiter varchar, part_number int32) → varchar` | Selected split part | Part number is `INT32`. |
| [SUBSTRING_INDEX](https://docs.dremio.com/current/reference/sql/sql-functions/functions/SUBSTRING_INDEX/) | `SUBSTRING_INDEX(varchar, delimiter varchar, count integer) → varchar` | Indexed substring | Count required. |
| [TOASCII](https://docs.dremio.com/current/reference/sql/sql-functions/functions/TOASCII/) | `TOASCII(string_expression string, character_encoding type) → string` | ASCII-converted string | Encoding type required. |
| [TRANSLATE](https://docs.dremio.com/current/reference/sql/sql-functions/functions/TRANSLATE/) | `TRANSLATE(base_expression varchar, source_characters varchar, target_characters varchar) → varchar` | Translated string | All three strings required. |
| [SUBSTR](https://docs.dremio.com/current/reference/sql/sql-functions/functions/SUBSTR/) | `SUBSTR(varchar, offset int64) → varchar`; `SUBSTR(varchar, offset int64, length int64) → varchar`; `SUBSTR(varchar, pattern varchar) → varchar` | Substring or regex-derived substring | Numeric offset/length forms and regex form are separate overloads. |

| [ST_FROMGEOHASH](https://docs.dremio.com/current/reference/sql/sql-functions/functions/ST_FROMGEOHASH/) | `ST_FROMGEOHASH(geohash varchar) → struct<latitude: double, longitude: double>` | Coordinates from geohash | Valid geohash required. |
| [ST_GEOHASH](https://docs.dremio.com/current/reference/sql/sql-functions/functions/ST_GEOHASH/) | `ST_GEOHASH(latitude double, longitude double [, precision integer]) → varchar` | Geohash | Precision is optional. |
