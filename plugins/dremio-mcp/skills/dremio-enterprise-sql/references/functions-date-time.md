# Date and time functions

Scope: Dremio Enterprise current [26.x]. Temporal return type depends on the documented overload; do not substitute similarly named functions.

| Function | Documented syntax | Result | Constraint |
| --- | --- | --- | --- |
| [CURRENT_DATE](https://docs.dremio.com/current/reference/sql/sql-functions/functions/CURRENT_DATE/) | `CURRENT_DATE\|CURRENT_DATE() → date` | Current local date | Current page permits bare and parenthesized forms. |
| [CURRENT_DATE_UTC](https://docs.dremio.com/current/reference/sql/sql-functions/functions/CURRENT_DATE_UTC/) | `CURRENT_DATE_UTC\|CURRENT_DATE_UTC() → date` | Current UTC date | Current page permits bare and parenthesized forms. |
| [CURRENT_TIME](https://docs.dremio.com/current/reference/sql/sql-functions/functions/CURRENT_TIME/) | `CURRENT_TIME\|CURRENT_TIME() → time` | Current local time | Current page permits bare and parenthesized forms. |
| [CURRENT_TIMESTAMP](https://docs.dremio.com/current/reference/sql/sql-functions/functions/CURRENT_TIMESTAMP/) | `CURRENT_TIMESTAMP\|CURRENT_TIMESTAMP() → timestamp` | Current timestamp | Current page permits bare and parenthesized forms. |
| [CONVERT_TIMEZONE](https://docs.dremio.com/current/reference/sql/sql-functions/functions/CONVERT_TIMEZONE/) | `CONVERT_TIMEZONE([sourceTimezone string], destinationTimezone string, timestamp date\|timestamp\|ISO-8601 string) → timestamp` | Timestamp in destination zone | Valid source/destination timezone identifiers required. |
| [DATE_ADD](https://docs.dremio.com/current/reference/sql/sql-functions/functions/DATE_ADD/) | `DATE_ADD(string\|date, integer) → date`; `DATE_ADD(string\|date\|timestamp, interval) → timestamp`; `DATE_ADD(time, interval) → time` | Advanced temporal value | Integer-day and interval overload families have different returns. |
| [DATE_SUB](https://docs.dremio.com/current/reference/sql/sql-functions/functions/DATE_SUB/) | `DATE_SUB(string\|date, integer) → date`; `DATE_SUB(string\|date\|timestamp, interval) → timestamp`; `DATE_SUB(time, interval) → time` | Rewound temporal value | Integer-day and interval overload families have different returns. |
| [DATEDIFF](https://docs.dremio.com/current/reference/sql/sql-functions/functions/DATEDIFF/) | `DATEDIFF(endDate string, startDate string) → integer` | Whole-day difference | End date is first. |
| [DATE_DIFF](https://docs.dremio.com/current/reference/sql/sql-functions/functions/DATE_DIFF/) | `DATE_DIFF(date, integer) → date`; `DATE_DIFF(date, date) → interval day`; `DATE_DIFF(timestamp, timestamp) → interval day`; `DATE_DIFF(time, interval) → time`; `DATE_DIFF(date, interval) → timestamp`; `DATE_DIFF(timestamp, integer\|interval) → timestamp` | Difference/subtraction by overload | Its return changes with the exact typed form. |
| [TIMESTAMPDIFF](https://docs.dremio.com/current/reference/sql/sql-functions/functions/TIMESTAMPDIFF/) | `TIMESTAMPDIFF(unit symbol, givenTime1 date\|timestamp, givenTime2 date\|timestamp) → integer` | Unit difference | Unit symbol and argument order are required. |
| [DATE_PART](https://docs.dremio.com/current/reference/sql/sql-functions/functions/DATE_PART/) | `DATE_PART(part string, date\|timestamp string) → bigint` | Requested temporal part | Use a documented part name. |
| [EXTRACT](https://docs.dremio.com/current/reference/sql/sql-functions/functions/EXTRACT/) | `EXTRACT(part FROM temporal_expression) → bigint` | Requested temporal part | `FROM` grammar is required. |
| [DATE_TRUNC](https://docs.dremio.com/current/reference/sql/sql-functions/functions/DATE_TRUNC/) | `DATE_TRUNC(unit string, temporal_expression date\|timestamp) → same temporal type` | Truncated temporal value | Unit controls granularity. |
| [DAY](https://docs.dremio.com/current/reference/sql/sql-functions/functions/DAY/), [DAYOFMONTH](https://docs.dremio.com/current/reference/sql/sql-functions/functions/DAYOFMONTH/), [DAYOFWEEK](https://docs.dremio.com/current/reference/sql/sql-functions/functions/DAYOFWEEK/), [DAYOFYEAR](https://docs.dremio.com/current/reference/sql/sql-functions/functions/DAYOFYEAR/), [HOUR](https://docs.dremio.com/current/reference/sql/sql-functions/functions/HOUR/), [MINUTE](https://docs.dremio.com/current/reference/sql/sql-functions/functions/MINUTE/), [MONTH](https://docs.dremio.com/current/reference/sql/sql-functions/functions/MONTH/), [QUARTER](https://docs.dremio.com/current/reference/sql/sql-functions/functions/QUARTER/), [SECOND](https://docs.dremio.com/current/reference/sql/sql-functions/functions/SECOND/) | `DAY\|DAYOFMONTH\|DAYOFWEEK\|DAYOFYEAR\|HOUR\|MINUTE\|MONTH\|QUARTER\|SECOND(date_timestamp_expression string) → bigint` | Integer temporal component | Each named function accepts the documented string temporal expression. |
| [WEEK](https://docs.dremio.com/current/reference/sql/sql-functions/functions/WEEK/), [WEEKOFYEAR](https://docs.dremio.com/current/reference/sql/sql-functions/functions/WEEKOFYEAR/), [YEAR](https://docs.dremio.com/current/reference/sql/sql-functions/functions/YEAR/) | `EXTRACT(WEEK\|YEAR FROM date_timestamp_expression string) → bigint` | Week/year component | `EXTRACT` grammar is documented for these functions. |
| [DATETYPE](https://docs.dremio.com/current/reference/sql/sql-functions/functions/DATETYPE/) | `DATETYPE(year numeric, month numeric, day numeric) → date` | Constructed date | Numeric fields required. |
| [TIMESTAMPTYPE](https://docs.dremio.com/current/reference/sql/sql-functions/functions/TIMESTAMPTYPE/) | `TIMESTAMPTYPE(year NUMERIC, month NUMERIC, day NUMERIC, hour NUMERIC, minute NUMERIC, second NUMERIC, millisecond NUMERIC) → DATE` | Constructed temporal value | The heading says it constructs a timestamp and its example displays `2020-10-05 01:02:03.500`, but the syntax says `DATE`. Do not treat `DATE` as settled; only the example-supported timestamp-shaped result is recorded here. |
| [LAST_DAY](https://docs.dremio.com/current/reference/sql/sql-functions/functions/LAST_DAY/) | `LAST_DAY(date_timestamp_expression string) → date` | Last day of month | String temporal input. |
| [NEXT_DAY](https://docs.dremio.com/current/reference/sql/sql-functions/functions/NEXT_DAY/) | `NEXT_DAY(date_timestamp_expression string, day_of_week string) → date` | Next weekday | Day name is required. |
| [MONTHS_BETWEEN](https://docs.dremio.com/current/reference/sql/sql-functions/functions/MONTHS_BETWEEN/) | `MONTHS_BETWEEN(date1 string, date2 string) → double` | Month difference | Argument order matters. |
| [OVERLAPS](https://docs.dremio.com/current/reference/sql/sql-functions/functions/OVERLAPS/) | `(start1, end1) OVERLAPS (start2, end2) → boolean` | Interval-overlap predicate | Pair syntax is required. |
| [TIMESTAMPADD](https://docs.dremio.com/current/reference/sql/sql-functions/functions/TIMESTAMPADD/) | `TIMESTAMPADD(unit symbol, count integer, givenTime date\|timestamp) → date\|timestamp` | Timestamp with interval added | Unit required. |
| [TO_DATE](https://docs.dremio.com/current/reference/sql/sql-functions/functions/TO_DATE/) | `TO_DATE(timestamp) → date`; `TO_DATE(int32\|int64\|float\|double) → date`; `TO_DATE(varchar, format [, replaceErrorWithNull int32]) → date` | Parsed date | The third string argument is an `INT32` null-on-error flag. |
| [TO_TIME](https://docs.dremio.com/current/reference/sql/sql-functions/functions/TO_TIME/) | `TO_TIME(int32\|int64\|float\|double) → time`; `TO_TIME(varchar, format [, replaceErrorWithNull int32]) → time` | Parsed time | The third string argument is an `INT32` null-on-error flag. |
| [TO_TIMESTAMP](https://docs.dremio.com/current/reference/sql/sql-functions/functions/TO_TIMESTAMP/) | `TO_TIMESTAMP(int32\|int64\|float\|double) → timestamp`; `TO_TIMESTAMP(varchar, format [, replaceErrorWithNull int32]) → timestamp` | Parsed timestamp | The third string argument is an `INT32` null-on-error flag. |
| [UNIX_TIMESTAMP](https://docs.dremio.com/current/reference/sql/sql-functions/functions/UNIX_TIMESTAMP/) | `UNIX_TIMESTAMP() → int64`; `UNIX_TIMESTAMP(varchar [, format varchar]) → int64` | Unix epoch seconds | Unit seconds. |
