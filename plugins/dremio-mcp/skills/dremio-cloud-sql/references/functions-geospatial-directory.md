# Geospatial and directory functions

Cloud SQL functions in the Geospatial and Directory categories. The Directory functions are linked from the current Cloud Directory category; their detail pages document only `dfs`/HDFS syntax and do not confirm Cloud executability.

| Function | Documented syntax and result | Load-bearing constraint | Source |
| --- | --- | --- | --- |
| GEO_BEYOND | `GEO_BEYOND(lat1 FLOAT, lon1 FLOAT, lat2 FLOAT, lon2 FLOAT, distance DOUBLE) -> BOOLEAN`; tests whether two points exceed a distance in metres. | Latitude/longitude must be `FLOAT` and distance must be `DOUBLE`; cast other types. | [docs](https://docs.dremio.com/dremio-cloud/sql/sql-functions/functions/GEO_BEYOND/) |
| GEO_DISTANCE | `GEO_DISTANCE(lat1 FLOAT, lon1 FLOAT, lat2 FLOAT, lon2 FLOAT) -> DOUBLE`; returns the point distance in metres. | All coordinate arguments must be `FLOAT`; it uses Haversine distance. | [docs](https://docs.dremio.com/dremio-cloud/sql/sql-functions/functions/GEO_DISTANCE/) |
| GEO_NEARBY | `GEO_NEARBY(lat1 FLOAT, lon1 FLOAT, lat2 FLOAT, lon2 FLOAT, distance DOUBLE) -> BOOLEAN`; tests whether two points are within a distance in metres. | Latitude/longitude must be `FLOAT` and distance must be `DOUBLE`; cast other types. | [docs](https://docs.dremio.com/dremio-cloud/sql/sql-functions/functions/GEO_NEARBY/) |
| ST_FROMGEOHASH | `ST_FROMGEOHASH(geohash VARCHAR) -> STRUCT<latitude: DOUBLE, longitude: DOUBLE>`; decodes a geohash centre point. | Input is a geohash string. | [docs](https://docs.dremio.com/dremio-cloud/sql/sql-functions/functions/ST_FROMGEOHASH/) |
| ST_GEOHASH | `ST_GEOHASH(latitude DOUBLE, longitude DOUBLE [, precision INTEGER]) -> VARCHAR`; encodes a point as geohash. | Precision defaults to 20 and must be from 1 through 20. | [docs](https://docs.dremio.com/dremio-cloud/sql/sql-functions/functions/ST_GEOHASH/) |
| IMAXDIR | `IMAXDIR('dfs', '<path_of_parent_directory>') -> <name_of_subdirectory>`; selects the highest case-insensitive directory name. | Public detail docs show only `dfs`/HDFS syntax; they do not confirm Cloud executability. | [docs](https://docs.dremio.com/dremio-cloud/sql/sql-functions/functions/IMAXDIR/) |
| IMINDIR | `IMINDIR('dfs', '<path_of_parent_directory>') -> <name_of_subdirectory>`; selects the lowest case-insensitive directory name. | Public detail docs show only `dfs`/HDFS syntax; they do not confirm Cloud executability. | [docs](https://docs.dremio.com/dremio-cloud/sql/sql-functions/functions/IMINDIR/) |
| LIST_FILES | `LIST_FILES(source_path VARCHAR) -> TABLE`; recursively lists source-directory files. | Source paths use `@source_name/path/to/directory` and follow the `COPY INTO` security model. | [docs](https://docs.dremio.com/dremio-cloud/sql/sql-functions/functions/LIST_FILES/) |
| MAXDIR | `MAXDIR('dfs', '<path_of_parent_directory>') -> <name_of_subdirectory>`; selects the highest case-sensitive directory name. | Public detail docs show only `dfs`/HDFS syntax; they do not confirm Cloud executability. | [docs](https://docs.dremio.com/dremio-cloud/sql/sql-functions/functions/MAXDIR/) |
| MINDIR | `MINDIR('dfs', '<path_of_parent_directory>') -> <name_of_subdirectory>`; selects the lowest case-sensitive directory name. | Public detail docs show only `dfs`/HDFS syntax; they do not confirm Cloud executability. | [docs](https://docs.dremio.com/dremio-cloud/sql/sql-functions/functions/MINDIR/) |
